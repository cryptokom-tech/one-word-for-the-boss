## The word

**GOTAMINUTE**

Every employee on earth has heard it: the boss appearing at your desk, or in your DMs, with "Got a minute?" — which is never a minute, and never a question. It is the single word a person would actually use about the one they report to: funny on its own with no caption needed, true of a real boss habit, fresh (nobody's first pick is the boss's own opener), and it travels — a kitchen, a warehouse or an office boss all say it the same way.

## How it works

`main.py` (Python 3, stdlib only) writes exactly one word to `/output/entry.txt`:

```
GOTAMINUTE
```

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
